# Optical-Properties
Optical Properties ((a) refractive index (b) extinction coefficient (c) absorption coefficient (d) optical reflectivity (e) real part of the dielectric function (f) imaginary part of the dielectric function) python code

# Optical Properties of 2D Materials (DFT-Based Analysis)

## What This Does
Calculates and visualizes optical properties (dielectric function,
absorption coefficient, refractive index) of 2D heterostructures
using VASP output files.

## Files
- `optical_analysis.py` — Main analysis script
- `data/` — Sample VASP OUTCAR / vasprun.xml files
- `plots/` — Output figures

## Requirements
Python 3.x, NumPy, Matplotlib, pymatgen (or ASE)
